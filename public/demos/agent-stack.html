Pipeline: /ads create → campaign live
01
creative-strategist
Read brand-profile.json + optional audit
Generates 3–5 campaign concepts. Each includes: hypothesis, primary message, tone axis, visual direction, platform fit, CTA, and image generation brief per placement.
02
copy-writer
Write copy deck from campaign-brief.md
Platform-compliant headlines (30 chars LinkedIn / 100 chars Meta), primary text variants, descriptions, and CTAs. Character counts validated before writing. Appended to campaign-brief.md.
03
visual-designer
Generate images via Gemini 2.5 Flash
Reads image generation briefs from campaign-brief.md. Calls generate_image.py for each concept × platform combination. Outputs to ad-assets/ with structured naming. Writes generation-manifest.json.
04
format-adapter
Validate dimensions and safe zones
Reads generation-manifest.json. Checks each asset: dimensions match platform spec, copy zones are clear, no missing formats. Writes format-report.md with PASS/FLAG/MISSING status per asset.
05
audit-creative · audit-meta · audit-google
Pre-launch audit sweep (on demand)
Run before uploading to ad platforms. Creative audit checks format diversity and fatigue signals. Meta audit checks Pixel/CAPI and EMQ scores. Google audit checks conversion tracking and Quality Score health.

Pipeline Outputs
📄
campaign-brief.md
Brand DNA summary, all campaign concepts, image generation briefs, and copy deck in one file. The single source of truth for the campaign.
strategic-strategist + copy-writer
🖼
ad-assets/
Platform-native images generated per concept. Named by concept slug and placement (e.g. concept-1-meta-feed-1080x1350.png).
visual-designer
📋
generation-manifest.json
Machine-readable asset registry. Lists every generated file, its dimensions, concept, platform, and safe zone status. Read by format-adapter.
visual-designer
✅
format-report.md
Per-asset PASS / FLAG / MISSING status. Flags dimension mismatches, cluttered copy zones, and missing placements before upload.
format-adapter
🔎
ADS-AUDIT-REPORT.md
Consolidated findings from all active audit agents. Feeds back into the next campaign cycle — creative-strategist reads it to address identified weaknesses.
audit-* agents
🧬
brand-profile.json
Persistent brand DNA: voice axes, colour palette, imagery style, audience pain points, mood keywords. Created once, consumed by every agent on every run.
