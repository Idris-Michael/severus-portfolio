Pipeline Steps
01
Obsidian Vault Sync
725 markdown notes auto-indexed. Tags, frontmatter, backlinks preserved as metadata.
02
Chunk + Embed
512-token chunks with 64-token overlap. OpenAI text-embedding-3-small (1536d). ChromaDB local store.
03
Semantic Retrieval
Cosine similarity top-k=5. Reranking via cross-encoder. Returns chunks + source note + confidence.
04
Context Injection
Retrieved chunks injected into system prompt. LangChain ConversationBufferMemory maintains thread.
05
Claude Generation
claude-haiku-4-5 reasons over context. Output stored back to vault as a linked note.
06
NotebookLM Synthesis
Selected vault notes → NotebookLM → audio briefing, slide deck, or mind map artifact.
