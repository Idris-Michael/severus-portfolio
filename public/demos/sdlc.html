Schema-on-Init Pattern
Each service runs CREATE TABLE IF NOT EXISTS on startup. No migration runner needed at current scale. Schema versioned in code.

Observability

Telegram Bot SQLite telemetry Run log table Error boundary GA4 events
01
Telegram Alert System
Every pipeline step posts status to Telegram. Errors trigger immediate alert with stack trace. Approval gate requires Telegram confirmation before publish.
02
Run History Table
Every agent invocation logged: skill, prompt, output, token count, duration, success. Queryable from hermes-hub Kanban and run history panels.
03
Error Policy
Fail loud — no silent catch blocks. Every catch logs to console + Telegram notification. Never swallow exceptions; surface them immediately.
