01 // SCRIPT GENERATION
Hook-first copywriting via Qwen3-32B
Generates 3 hook variants per post — social-proof, direct-offer, and curiosity-gap styles. Injects last 5 published hooks to prevent repetition. Output: 60-word script + caption + 10 hashtags.
HF Inference API · ~$0.00005/run
02 // VOICE SYNTHESIS
Cloud TTS with emotion tags via Gemini
Converts script to MP3 using Google Gemini TTS. Supports BCP-47 voice tags for 40+ languages. Fallback to local Supertonic Flask server (port 8765) if Gemini is unavailable.
Gemini TTS · ~$0.000016/char
03 // VIDEO RENDER
JSON-to-MP4 via Hyperframes
Renders 9:16 reels from a Hyperframes JSON template. Combines voiceover audio, B-roll footage, captions, and brand overlays. Outputs 5 variants per run with different hook styles.
Hyperframes · Local render · $0
04 // APPROVAL + PUBLISH
Telegram gate → Meta Graph API
Sends rendered variants to Telegram for human review with HMAC-signed approval links. On approval, uploads video to Meta via resumable upload API and schedules the reel.
Meta Graph API · Bot: @severus_connects
